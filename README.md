# WIland - Windows Dynamic Island

A dynamic island for Windows: a black notch at the top of the screen that springs open into what's happening. Media you're playing, timers, battery and devices, a file shelf, clipboard history and an app launcher.

This repo only holds the installers. Each release is built automatically.

## Install

1. Open the [latest release](https://github.com/ne-wtn/WIland-Releases/releases/latest) and download `WIland-Setup-x.y.z.exe`.
2. Run it. The installer isn't code-signed yet, so Windows may say "Windows protected your PC". Choose **More info → Run anyway**.

Windows 10 or 11, 64-bit.

## Updates

The app updates itself: it checks on launch and every few hours, downloads new versions quietly, and installs them when you restart it. You can also check from **General → Updates**.

## Getting around

- Hover the top centre of the screen to peek, click to open.
- Right-click the left or right side of the open island to switch pages.
- Drag a file onto the island to keep it on the shelf.
- **Alt+Shift+Space** opens the launcher.
